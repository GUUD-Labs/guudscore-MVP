# gUUd

The gUUd web application lives at **[app.guud.fun](https://app.guud.fun)**.

## What is gUUd?

gUUd (GuudScore) is a multi-chain reputation and community platform for the crypto ecosystem. It analyzes wallet activity, NFT holdings, protocol interactions and social engagement to give every user an on-chain reputation score — and turns that reputation into a game.

### Features
- **gUUd Score** — per-network and aggregate reputation scores built from on-chain behavior, with seasonal badges and historical tracking
- **Multi-chain** — Avalanche, Solana, Base, Arbitrum, Monad and Robinhood Chain
- **Vouch** — users vouch for (or against) each other to build social reputation
- **Prediction Markets** — bet on community outcomes, with user-proposed markets voted on by the community
- **NFT Cemetery & Awaken** — burn NFTs for points; the community votes weekly on which burned NFT gets awakened
- **Weekly Pool & Spin** — weekly point pool, daily spin wheel with multipliers
- **Leaderboards & Profiles** — public profiles, GuudCard NFTs, referral rewards and Arena/X (Twitter) activity integration
